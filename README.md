# Spunky pipeline status

Live dashboard: https://shalevsharfsh.github.io/spunk-status/

Static page; all data is fetched in the browser with your own read-only GitHub PAT (never stored here).
`index.html` is the single source of truth — edit it here and push to update the live site.
Pipelines shown are configured in the `WORKFLOWS` array; runner repos in `RUNNER_REPOS`.
